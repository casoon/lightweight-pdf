`en16931-sample.xml` is `hate1.xml` from the
[ZUGFeRD/corpus](https://github.com/ZUGFeRD/corpus) test corpus
(`ZUGFeRDv2/correct/Mustangproject/hate1.xml`, generated by the
[Mustang Project](https://www.mustangproject.org/), the reference
open-source ZUGFeRD/Factur-X implementation) — Apache-2.0 licensed, used
here unmodified as a real, EN 16931-conformant `CrossIndustryInvoice`
document (`GuidelineSpecifiedDocumentContextParameter` =
`urn:cen.eu:en16931:2017`) for `examples/demo_zugferd.rs` and the
`zugferd`-feature tests: this crate embeds XML, it doesn't generate it
(see ADR-018 in the local `plan/00-decisions.md`), so testing the
embedding path needs a real invoice XML from somewhere.
